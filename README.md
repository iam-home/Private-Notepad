# Privata Notepad

고2 때 파이썬을 배우고, VSEPR 시뮬레이터를 만들고, 그 다음으로 만든 프로그램입니다.

## 만들게 된 배경
이 당시 저는 게임 개발에 관심이 있었습니다. 특히 로그인을 해서 정보를 저장하고, 다른 유저들도 볼 수 있게 하는 멀티 플레이에 관심이 있었습니다.
그러던 중, 유튜브에서 한 영상을 보게 됩니다. 마인크래프트 구조물 블록으로 저장하고 불러오기를 하는 영상이었습니다.
영상에서는 구조물 블록은 저장을 컴퓨터 폴더에 따로 저장이 된다는 점을 이용해서 저장 기능을 만들 아이디어를 갖고 있었습니다.

저는 이것을 보고, '컴퓨터에 따로 저장이 되는 파일을 갖고 저장, 불러오기를 만드는 거면 파일 입출력으로도 로그인 기능을 만들 수 있는 거 아닐까?'라는 생각을 했습니다.

컴퓨터에 따로 저장 -> txt,
저장/불러오기 -> 로그인 정보

그럴듯했습니다. 실제로 만들기도 했는데, 너무 휑하더라고요. 아무래도 수행평가로 제출해야 되는 건데 이렇게 휑하면 안될 거 같았습니다.
그래서 지금 만든 이 로그인 비스무리한 것을 활용해서 더 만들 수 있는 게 없을까 생각하던 중 떠오른 만만한 것이 개인별 노트패드였습니다.

아이디를 입력하는 부분을 노트의 이름으로 바꾸고,
비밀번호를 입력하는 부분은 노트의 비밀번호로 바꿨습니다.
